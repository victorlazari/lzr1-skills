# Quality Assurance Source Map (2026)

**Verified against upstream: 2026-08-07**

This reading list serves as a source map. Use it to determine which standard governs a specific domain and when to consult it.

## Authoritative Standards (Normative)

1. **ISO/IEC/IEEE 29119 Software Testing Standard**
   - **Governs**: Test processes, documentation, techniques, and AI testing (Part 11).
   - **When to consult**: Designing formal test strategies, creating test plans, establishing QA processes, or testing AI-based systems.
   - **URL**: https://softwaretestingstandard.org/

2. **ISTQB Certified Tester Advanced Level Test Automation Engineering (CTAL-TAE) v2.0**
   - **Governs**: Test automation architecture, framework design, and CI/CD integration.
   - **When to consult**: Building or refactoring test automation frameworks, defining automation strategy.
   - **URL**: https://istqb.org/certifications/certified-tester-advanced-level-test-automation-engineering-ctal-tae-v2-0/

3. **OWASP Web Security Testing Guide (WSTG)**
   - **Governs**: Web application security testing methodologies and vulnerability assessment.
   - **When to consult**: Planning security tests, identifying web vulnerabilities, or integrating security into the QA process.
   - **URL**: https://owasp.org/www-project-web-security-testing-guide/latest/

## Essential Books & Resources (Supplementary)

### Testing Strategy & Fundamentals
- **Lessons Learned in Software Testing** — Kaner, Bach & Pettichord (2001).
- **Agile Testing** — Lisa Crispin & Janet Gregory (2009).
- **Explore It!** — Elisabeth Hendrickson (2013). Exploratory testing.

### Test Automation
- **Playwright Docs** — playwright.dev. Modern E2E framework.
- **Cypress Docs** — docs.cypress.io. Frontend testing.
- **Test Automation University** — testautomationu.applitools.com. Free courses.

### Performance Testing
- **k6 Documentation** — k6.io/docs. Load testing.
- **Systems Performance** — Brendan Gregg (2nd ed, 2020).
- **web.dev Performance** — web.dev/performance. Web performance.

### API Testing
- **Testing Web APIs** — Mark Winteringham (2022).
- **Postman Learning Center** — learning.postman.com. API testing.

### Security Testing
- **The Web Application Hacker's Handbook** — Stuttard & Pinto (2nd ed, 2011).
- **PortSwigger Web Security Academy** — portswigger.net/web-security. Free security training.

### Quality Engineering & DevOps
- **Accelerate** — Forsgren, Humble & Kim (2018). DevOps metrics.
- **DORA Metrics** — dora.dev. DevOps research and assessment.
- **Site Reliability Engineering** — Google (2016). SRE practices.
