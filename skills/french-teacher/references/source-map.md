## Verification Rules

1. **CEFR Alignment:** All generated materials must be verified against the official Council of Europe CEFR descriptors.
2. **Grammar Accuracy:** Grammar explanations must align with the standards set by the Académie Française and established curricula like CCFS Sorbonne.
3. **Source Freshness:** When dealing with volatile facts (e.g., recent changes in orthography), consult the Académie Française website and note the verification date.
