## Configuration
- Always validate configuration schemas before deployment.
- Use `openclaw check-config` for syntax validation.

## Troubleshooting
- Check gateway logs: `tail -f /var/log/openclaw/gateway.log`
- Verify memory state: `openclaw memory status`
