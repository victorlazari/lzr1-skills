# Sections Encyclopedia

Standardized content for README sections.

## 1. Header and Badges
The top of the README. Must include the project name, a short description, and relevant badges.
*For pyOpenSci:* Badges are strictly defined (CI, docs, Python versions, PyPI version).

## 2. Quick Start / Installation
Clear, copy-pasteable installation instructions.
Provide instructions for both stable (PyPI/Conda) and development (source) installations.

## 3. Usage / Tutorial
A brief demonstration of the package.
Use dynamic media (GIFs/Videos) here to show the tool in action.

## 4. Documentation
Link to the full documentation website (e.g., ReadTheDocs, GitHub Pages).

## 5. Comparison (Scientific Packages)
*Required for pyOpenSci:* Explain how the package compares to similar tools in the scientific ecosystem.

## 6. Citation
Provide citation information (BibTeX or citation file link) so researchers can credit the software.

## 7. Contributing
Link to `CONTRIBUTING.md` and state the code of conduct.
