# Google Chat Integration Reference

The Google Chat API allows the bot to manage spaces, members, and messages. This integration is essential for building conversational interfaces and automated notifications within Google Chat.

## Core Capabilities

The bot can create and manage spaces, add or remove members, and send messages. It supports standard Markdown syntax for rich text formatting in messages. The bot can also search for messages within spaces and manage granular access permissions.

## Action Categories and Examples

| Action Category | Description | Example Bot Command |
| :--- | :--- | :--- |
| **Space Management** | Create and configure spaces. | *"Create a new space called 'Project Alpha Team'."* |
| **Message Sending** | Send messages with standard Markdown syntax. | *"Send a message to the 'General' space with a bold heading and a bulleted list."* |
| **Message Search** | Search for specific messages within spaces. | *"Find all messages in the 'Support' space containing the word 'urgent'."* |
